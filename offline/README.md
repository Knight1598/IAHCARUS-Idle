## เล่นผ่านลิงก์

workflow **Deploy IAHCARUS to GitHub Pages** คัดลอกไฟล์ `offline/Special-Chess-Offline.html` ที่ commit ไว้ไปเป็นหน้าเว็บหลักโดยตรง ไม่ build หรือแก้ไฟล์เกม หลังเปิด Pages และ deploy สำเร็จ ใช้ลิงก์เดิม `https://knight1598.github.io/IAHCARUS-Idle/` ได้ตลอด ไม่ต้องดาวน์โหลดไฟล์หรือเปิดเซิร์ฟเวอร์เอง

## Special Duel — อัลติพลิกกระดาน

เลือก **Special Duel** → เลือกบอตหรือสองคนบนเครื่องเดียว → จัดกองทัพและสนาม → เริ่มเล่น แต่ละฝ่ายมีอัลติรวม 3 ครั้ง หมากแต่ละตัวใช้ได้ครั้งเดียว สกินไม่มีผลต่อกติกา

- ม้าเดินแบบควีนหนึ่งตา แต่ข้ามหมากไม่ได้
- บิชอปเดินตรงได้ 1–2 ช่อง เรือเดินทแยงได้ 1–2 ช่อง ควีนกระโดดแบบม้า
- เบี้ยกินตรงหน้าได้หนึ่งช่องและเลื่อนขั้นได้ คิงเคลื่อนตรง 2 ช่องผ่านช่องว่างที่ปลอดภัยและกินไม่ได้
- เลือกหมาก → กดอัลติ → เลือกเป้าหมาย → ยืนยัน ยกเลิกก่อนยืนยันไม่เสียพลัง
- อัลติใช้แทนการเดินหนึ่งตา หลังเดินรูปการขู่กลับเป็นปกติ คิงต้องปลอดภัย และการรุกฆาตต้องไม่มีทั้งทางเดินปกติและอัลติที่ช่วยหนีได้
- แถบพลังแสดงสิทธิ์ทั้งสองฝ่าย เพชรเล็กที่พื้นแสดงหมากที่ยังมีอัลติ เปิดคู่มือเพื่อดูสกิลและแนวเดินที่ศัตรูอาจใช้ได้จากตำแหน่งปัจจุบัน
- บอตใช้กติกาเดียวกัน ย้อนตาแล้วคืนพลัง เซฟแล้วกลับมาเล่นต่อได้ รีเพลย์การกินหมากไม่เปลี่ยนเกม และหน้าจบมีรีแมตช์สลับสี
- โหมดนี้ใช้ได้ออฟไลน์และสองคนบนเครื่องเดียว ห้องออนไลน์ยังเป็นหมากรุกมาตรฐาน ไฟล์บันทึก Variant ใช้สัญลักษณ์ `U:` จึงไม่ใช่ PGN หมากรุกมาตรฐาน

## เปิดเล่น

1. ดาวน์โหลดไฟล์ [`Special-Chess-Offline.html`](./Special-Chess-Offline.html) จาก GitHub ด้วยปุ่ม **Download raw file**
2. เปิดไฟล์ที่ดาวน์โหลดด้วย Chrome หรือ Edge บนคอมพิวเตอร์
3. กด **เริ่มดวล → เข้าสู่ศึก** เลือกโหมด เตรียมศึก จัดกองทัพ และเลือกสนาม แล้วกด **เข้าสู่สนาม** หรือเลือก **เล่นศึกที่บันทึกไว้ต่อ** จากเมนูหลัก
4. แตะหมากของฝ่ายที่ถึงตา แล้วแตะช่องปลายทางเพื่อเดิน

ไฟล์เดียวรวมโมเดล 3D เอฟเฟกต์ คัตซีน เสียง และบอตไว้แล้ว ไม่ต้องใช้ Node.js ไม่ต้องรันเซิร์ฟเวอร์ และไม่ต้องต่ออินเทอร์เน็ตระหว่างเล่น อย่าเปิดผ่านหน้าแสดงโค้ด HTML ของ GitHub ให้ดาวน์โหลดก่อน

- เลือกเล่นฝ่ายขาวหรือดำกับบอตได้ หรือเลือก **ประลองสองคน** เพื่อผลัดกันเล่นบนเครื่องเดียว
- เลือกสนามได้ 8 แบบก่อนเริ่มหรือในตั้งค่า: ราชวังดารา เตาหลอมอัคนี วิหารเหมันต์ รอยแยกจักรวาล ยอดผาอัสนี พงไพรจันทรา แกนปฏิกรณ์นีออน และสุสานสุริยคราส แต่ละสนามมีโครงสร้าง แสง อนุภาค และเอฟเฟกต์ปะทะของตัวเอง ตัวเลือกบันทึกในเครื่อง
- ฉากสังหารมีอวตารทั้งฝ่ายโจมตีและฝ่ายรับ ใช้สกินของแต่ละตัว ขยับสะโพก ลำตัว หัว ศอก เข่า และผ้าคลุม มีถ่ายน้ำหนัก ง้างท่า ฟัน แทง แรงสะบัด และคืนท่าต่างกันทั้ง 6 คลาส กล้องปรับตามสัดส่วนจอให้เห็นทั้งคู่
- เอฟเฟกต์ใหม่มีเกลียวชาร์จพลัง วงเวทหลายชั้น คมอาวุธขอบฟุ้ง คลื่นแรงดัน ประกายและเศษคริสตัล โล่ขอบเรืองแสง ออร่าไหลขึ้นรอบตัว และแรงปะทะเฉพาะสนามทั้ง 8 แบบ ลดจำนวนอนุภาคได้ผ่านตัวเลือกกราฟิก
- มีสกินเริ่มต้น 3 ชุด และสกินปลดล็อกที่เลเวล 2 กับ 4 รูปทรงทุกหมาก อวตาร และเอฟเฟกต์สร้างจากโค้ด เลือกสกินแยกได้ทุกตัวผ่านคลังแสง
- มีด่านสั้น 3 บท: ช่วยคิง ขู่สองตัว และรุกฆาตในสองตา รับ 60 / 80 / 100 XP เมื่อผ่านครั้งแรก
- **ศึกประจำวัน** มีโจทย์ช่วยราชัน ขู่สองตัว และรุกฆาต หมุนเวียน 16 กระดาน พร้อมสนามแนะนำ เปลี่ยนทุกวันเวลา 07:00 น. ของไทย (00:00 UTC) รับ 80 XP เมื่อผ่าน เพิ่มวันละ 10 XP หากผ่านต่อเนื่อง สูงสุด 120 XP รางวัลรับครั้งเดียวต่อวันที่ระบุ เล่นซ้ำหรือ Undo ได้โดยไม่เพิ่ม XP ซ้ำ
- เกมประจำวันที่เซฟไว้ยังเล่นต่อจากกระดานและวันที่เดิมได้หลังเปลี่ยนวัน เลือกศึกประจำวันใหม่จากเมนูเพื่อเล่นโจทย์วันนี้ สถิติเล่นต่อเนื่องและรางวัลเก็บในเบราว์เซอร์เดียวกับโปรไฟล์เดิม
- เมนูเน้นเริ่มดวลและเลือกคู่แข่ง โจทย์ประจำวันอยู่ใต้ปุ่มดวล ส่วนแต้มสะสมและการปลดล็อกสกินอยู่ในคลังแสง
- กระดานใช้แผ่นโลหะสลักลาย ขอบเรืองแสง จุดเขียวแสดงช่องเดิน และกรอบชมพูแสดงช่องกินหมาก กระดาน 2D แสดงตาล่าสุดและคิงที่ถูกรุกด้วย
- เลือกหมากแล้ววางเมาส์เหนือช่องเป้าหมายเพื่อดูเส้นทาง พรีวิวการกินหมาก การรุก และแนวคุมของคู่แข่งก่อนเดินจริง ใช้เมาส์หรือโฟกัสด้วยคีย์บอร์ดบนกระดาน 2D ได้เช่นกัน พรีวิวไม่แก้เกมหรือเซฟ
- คลังแสงแสดงหมากจริงใน 3D เลือกสกินให้แต่ละตัวและกดทดลองท่าได้โดยไม่เปลี่ยนเกมที่บันทึกไว้
- หน้าจบศึกแสดงหมากเด่นและ XP กดดูฉากสังหารซ้ำ เล่นต่อ หรือกลับค่ายได้
- จบเกมกับบอตและทำภารกิจเพื่อรับ XP; สนามฝึกให้ 40 XP เมื่อผ่านแต่ละฉากครั้งแรก ทุก 200 XP เพิ่มหนึ่งเลเวล โปรไฟล์บันทึกในเบราว์เซอร์นี้
- เปิดจาก **Title → เมนูหลัก → เลือกโหมด → เตรียมศึก → จัดกองทัพ → เลือกสนาม → เข้าสู่สนาม** ย้อนกลับได้โดยเก็บตัวเลือกไว้ ปุ่มเริ่มศึกอยู่หน้าสนามขั้นสุดท้าย
- **☰ เมนู** หรือ Escape เปิดเมนูพักเกม หยุดบอตและคัตซีนออฟไลน์จริง ตั้งค่า ภารกิจ บันทึก ระดับบอต และเกมใหม่อยู่ในเมนูนี้ ปุ่มหลักระหว่างเล่นอยู่บนจอ ไม่ต้องเลื่อนหน้าเว็บ
- **กลับเมนูหลัก** กลับค่ายและเก็บเซฟไว้ กด **เล่นศึกที่บันทึกไว้ต่อ** เพื่อเล่นต่อได้ทันที
- **ง่าย** ประเมินการเดินทันที เหมาะกับฝึกเล่น
- **ปานกลาง** คิดถึงการตอบโต้ของคู่แข่ง
- **ยาก** มองล่วงหน้าเพิ่มขึ้น และอาจใช้เวลาคิดมากขึ้นบนเครื่องช้า
- ปรับระดับระหว่างเกมได้ เกมและระดับล่าสุดบันทึกในเบราว์เซอร์เมื่ออนุญาตให้ใช้ local storage
- ปุ่ม **ย้อนตา** ย้อนทั้งตาคุณและบอต การย้อนตาหรือโหลดเกมซ้ำไม่เพิ่ม XP ที่รับไปแล้ว
- **สนามฝึกท่าสเปเชียล** ใช้ทดลองฉากต่าง ๆ โดยควบคุมทั้งสองฝ่ายเอง กดเกมใหม่เพื่อกลับไปสู้บอต
- ปุ่มเกมใหม่ ย้อนตา กล้อง ข้ามฉาก 2D และปิดเสียงอยู่บน HUD ด้านล่าง ตั้งค่า ฝึก ภารกิจ และบันทึกเปิดเป็นแผงในจอ ไม่ต้องเลื่อนหน้า ปิดแผงด้วย ✕ หรือ Escape
- คัตซีนสไตล์อนิเมะ: ชาร์จออร่า เส้นสปีดที่ขอบจอ พุ่งโจมตี ค้างจังหวะปะทะ และคลื่นระเบิดพลัง ชื่อท่าและอีเวนท์เป็นแถบข้างสไลด์เข้าออก
- ออร่าพื้นหมุนและหายใจตอนยืน รอยร้าวพลังตามทางเดินจะค่อยจางภายใน 7 วินาที
- ทุกการเดินมีวงออร่าที่พื้น ชาร์จก่อนพุ่ง กรอบล็อกเป้า ทางพลัง และสโลว์โมก่อนถึงเป้า เวลาสังหารจะเข้าประชิด ง้างท่า อวตารโจมตี ศัตรูรับแรงแล้วสลาย ก่อนเข้าประจำช่อง รูปทรงและท่าทางต่างกันตามชนิดหมาก
- เปิด **เสียงอวกาศ · ไซไฟอนิเมะ** เพื่อฟังเสียงล็อกเป้า ชาร์จ บีม พุ่ง และปะทะ ปรับความดังด้วยแถบ **ระดับเสียงเอฟเฟกต์** ได้
- เสียงเดิน โจมตี ปะทะ ตาย และรุก มีอย่างละ 4 แบบต่อหมาก สลับไม่ซ้ำติดกัน พร้อมเสียงอีเวนท์ขู่สองตัว รุกฆาต และจังหวะสำคัญ
- เสียงแต่ละหมากใช้บุคลิกต่างกัน: เบี้ยแทงสั้น ม้าพัลส์ฉีกอากาศ บิชอปบีมค้าง รุคมอเตอร์และปืนใหญ่ ควีนคริสตัลไล่ระดับ คิงคอร์ดโล่หนัก ปุ่มปิดเสียงบน HUD ไม่ข้ามฉากต่อสู้
- คัตซีนข้ามได้ ลดเอฟเฟกต์ได้ และเสียงเปิด/ปิดได้
- ลองฉาก **ม้า · พุ่งทะลวงเงา** ในสนามฝึก แล้วเดิน c3 → d5 เพื่อดูฉากโจมตีใหม่ทันที

## สร้างไฟล์ใหม่จาก source

ใช้ Node.js 24 ในโฟลเดอร์ repository:

```sh
npm ci
npm run build:offline
npm run test:offline
```

ไฟล์ส่งให้คนทดสอบอยู่ที่ `offline/Special-Chess-Offline.html` โฟลเดอร์ `dist-offline` เป็นผล build ชั่วคราว

สำหรับแก้โค้ดพร้อมดูผล ใช้ `npm run dev:offline` แล้วเปิดหน้า `/offline.html` ของ Vite ไม่ต้องเปิด multiplayer server

## การทดสอบ

ทดสอบไฟล์ที่แพ็กแล้วด้วย Chromium โดยปิดเครือข่าย ผ่านบอตทั้งสามระดับ การเซฟ/ย้อนตา ยกเลิกการคิด สนามฝึก และหน้าจอขนาดมือถือ ไม่มี request ภายนอกหรือ WebSocket

`npm run test:daily` ตรวจศึกประจำวันบนมือถือ รางวัลไม่ซ้ำ เล่นต่อข้ามวัน และโบนัสเล่นต่อเนื่อง ส่วน `npm test` ตรวจว่าโจทย์ทั้ง 16 กระดานเดินถูกกติกาและทำเป้าหมายได้จริง

เครื่อง cloud นี้มีนโยบายเบราว์เซอร์บล็อก `file://` จึงส่ง HTML เดียวกันให้เบราว์เซอร์ผ่านหน่วยความจำแทน (`OFFLINE_TEST_TRANSPORT=memory npm run test:offline`) การดับเบิลคลิกเปิดไฟล์จริงยังไม่ได้ยืนยันในเครื่องนี้ ชุดทดสอบปกติและ CI ใช้ `file://` โดยตรง

การเปิดไฟล์ HTML บนมือถือจริงขึ้นกับเบราว์เซอร์และแอปจัดการไฟล์ของอุปกรณ์ ยังต้องทดสอบบน Android/iOS เพิ่ม

`npm run test:tactics` ตรวจเมนูเริ่มดวล พรีวิวการเดินโดยไม่เปลี่ยนประวัติ การเล่นจริง และหน้าจอมือถือ ส่วน `npm run test:render` ตรวจเป้า 3D การเลื่อนเมาส์จริง การคืนหน่วยความจำและภาระการวาดกระดาน

## โหมดใหม่และตัวตนผู้เล่น

หน้าเลือกโหมดแบ่งเป็น ดวล / อารีนา / ยุทธวิธี และเพิ่ม Draft Arena, Score Clash, Control Arena, Mirror Duel, Puzzle Rush และ Chaos Arena กติกาสรุปและแถบเป้าหมายแยกตามโหมด เลือกบอตสามระดับหรือสองคนบนเครื่องเดียวได้ ยกเว้น Rush ซึ่งเป็นโจทย์รุกฆาตหนึ่งตา 3 นาที พลาดได้ 3 ครั้ง มีปุ่มโจทย์ถัดไปและสถิติในเครื่อง

Mirror Duel เล่นสองรอบสลับสี คะแนนติดตามผู้เล่นเดิมแม้เปลี่ยนฝ่าย เสมอได้ฝ่ายละครึ่งแต้ม ส่วน Chaos แสดงเฟสปัจจุบันและรอบถัดไป: เดินปกติ → ม้าเดินทแยงหนึ่งช่องเพิ่ม → บิชอปเดินตรงหนึ่งช่องเพิ่ม แนวรุกคิงยังตามการเดินปกติของหมาก

รหัสท้าดวลใช้แชร์ชุดหมาก สนาม และกติกาเดิมให้เพื่อนลองได้ โดยไม่ได้เชื่อมห้องออนไลน์

ปุ่มสร้างตัวละครเปิดตัวออกแบบรูปทรง ตราประจำตัว สีและชื่อ โปรไฟล์เก็บในเบราว์เซอร์นี้ ไม่มีการเก็บรหัสผ่านในไฟล์ออฟไลน์ การสมัครบัญชีจริงต้องเปิดเกมรุ่น Node บนเซิร์ฟเวอร์ ดูรายละเอียดใน ACCOUNT_DEPLOYMENT.md

## ท้าดวลกับเพื่อนคนละเครื่อง

ไฟล์เกมบน GitHub Pages มีโหมด **ท้าดวลกับเพื่อน** เพิ่มแล้ว โหมดนี้ต้องต่ออินเทอร์เน็ตและใช้เซิร์ฟเวอร์ WebSocket แยก โดยโหมดบอต/สองคนเครื่องเดียวยังเล่นออฟไลน์ได้เหมือนเดิม เปิดห้อง ส่งลิงก์ให้เพื่อน แล้วกดพร้อมทั้งคู่เพื่อเริ่มนาฬิกา รอบแรกใช้หมากรุกปกติ สกินส่วนตัว และกลับเข้าห้องจากเบราว์เซอร์เดิมได้ขณะเซิร์ฟเวอร์ยังทำงาน ดูขั้นตอนเปิด Render และตั้งค่า Pages ที่ [FRIEND-DUELS.md](../docs/FRIEND-DUELS.md)
