# Special Chess 3D — Offline Bot Edition

เวอร์ชันทดสอบแยกสำหรับเล่นกับบอต **ง่าย / ปานกลาง / ยาก**

## เล่นผ่านลิงก์

เตรียมระบบเผยแพร่ GitHub Pages แล้ว หลังเปิด Pages และ workflow **Publish bot game** สำเร็จ ลิงก์เริ่มต้นจะเป็น `https://knight1598.github.io/IAHCARUS-Idle/` ไม่ต้องดาวน์โหลดไฟล์หรือเปิดเซิร์ฟเวอร์เอง

ตั้งค่าครั้งแรก: repository **Settings → Pages → Source: GitHub Actions** แล้วไป **Actions → Publish bot game → Run workflow** หากยังไม่มี deployment สำเร็จ ดู URL ที่ GitHub รายงานหลัง deploy ก่อนแชร์ลิงก์

## เปิดเล่น

1. ดาวน์โหลดไฟล์ [`Special-Chess-Offline.html`](./Special-Chess-Offline.html) จาก GitHub ด้วยปุ่ม **Download raw file**
2. เปิดไฟล์ที่ดาวน์โหลดด้วย Chrome หรือ Edge บนคอมพิวเตอร์
3. ที่ค่ายบัญชาการ เลือกโหมด ฝ่าย คู่ปรับ และชุดหมาก แล้วกด **เริ่มเกมใหม่** หรือ **เล่นเกมที่บันทึกไว้ต่อ**
4. แตะหมากของฝ่ายที่ถึงตา แล้วแตะช่องปลายทางเพื่อเดิน

ไฟล์เดียวรวมโมเดล 3D เอฟเฟกต์ คัตซีน เสียง และบอตไว้แล้ว ไม่ต้องใช้ Node.js ไม่ต้องรันเซิร์ฟเวอร์ และไม่ต้องต่ออินเทอร์เน็ตระหว่างเล่น อย่าเปิดผ่านหน้าแสดงโค้ด HTML ของ GitHub ให้ดาวน์โหลดก่อน

- เลือกเล่นฝ่ายขาวหรือดำกับบอตได้ หรือเลือก **ประลองสองคน** เพื่อผลัดกันเล่นบนเครื่องเดียว
- เลือกสนามได้ 8 แบบก่อนเริ่มหรือในตั้งค่า: ราชวังดารา เตาหลอมอัคนี วิหารเหมันต์ รอยแยกจักรวาล ยอดผาอัสนี พงไพรจันทรา แกนปฏิกรณ์นีออน และสุสานสุริยคราส แต่ละสนามมีโครงสร้าง แสง อนุภาค และเอฟเฟกต์ปะทะของตัวเอง ตัวเลือกบันทึกในเครื่อง
- ฉากสังหารมีอวตารทั้งฝ่ายโจมตีและฝ่ายรับ ใช้สกินของแต่ละตัว แขนและอาวุธขยับตามท่าเฉพาะคลาส พร้อมออร่าหลายชั้น กล้องปรับตามสัดส่วนจอให้เห็นทั้งคู่
- มีสกินเริ่มต้น 3 ชุด และสกินปลดล็อกที่เลเวล 2 กับ 4 รูปทรงทุกหมาก อวตาร และเอฟเฟกต์สร้างจากโค้ด เลือกสกินแยกได้ทุกตัวผ่านคลังแสง
- มีด่านสั้น 3 บท: ช่วยคิง ขู่สองตัว และรุกฆาตในสองตา รับ 60 / 80 / 100 XP เมื่อผ่านครั้งแรก
- คลังแสงแสดงหมากจริงใน 3D เลือกสกินให้แต่ละตัวและกดทดลองท่าได้โดยไม่เปลี่ยนเกมที่บันทึกไว้
- หน้าจบศึกแสดงหมากเด่นและ XP กดดูฉากสังหารซ้ำ เล่นต่อ หรือกลับค่ายได้
- จบเกมกับบอตและทำภารกิจเพื่อรับ XP; สนามฝึกให้ 40 XP เมื่อผ่านแต่ละฉากครั้งแรก ทุก 200 XP เพิ่มหนึ่งเลเวล โปรไฟล์บันทึกในเบราว์เซอร์นี้
- ปุ่ม **หน้าหลัก** กลับหน้าไตเติลและพักการคิดของบอต เกมที่บันทึกไว้ยังเล่นต่อได้
- **ง่าย** ประเมินการเดินทันที เหมาะกับฝึกเล่น
- **ปานกลาง** คิดถึงการตอบโต้ของคู่แข่ง
- **ยาก** มองล่วงหน้าเพิ่มขึ้น และอาจใช้เวลาคิดมากขึ้นบนเครื่องช้า
- ปรับระดับระหว่างเกมได้ เกมและระดับล่าสุดบันทึกในเบราว์เซอร์เมื่ออนุญาตให้ใช้ local storage
- ปุ่ม **ย้อนตา** ย้อนทั้งตาคุณและบอต การย้อนตาหรือโหลดเกมซ้ำไม่เพิ่ม XP ที่รับไปแล้ว
- **สนามฝึกท่าสเปเชียล** ใช้ทดลองฉากต่าง ๆ โดยควบคุมทั้งสองฝ่ายเอง กดเกมใหม่เพื่อกลับไปสู้บอต
- ปุ่มเกมใหม่ ย้อนตา กล้อง ข้ามฉาก 2D และปิดเสียงอยู่บน HUD ด้านล่าง ตั้งค่า ฝึก ภารกิจ และบันทึกเปิดเป็นแผงในจอ ไม่ต้องเลื่อนหน้า ปิดแผงด้วย ✕ หรือ Escape
- คัตซีนสไตล์อนิเมะ: ชาร์จออร่า เส้นสปีดที่ขอบจอ พุ่งโจมตี ค้างจังหวะปะทะ และคลื่นระเบิดพลัง ชื่อท่าและอีเวนท์เป็นแถบข้างสไลด์เข้าออก
- ออร่าพื้นหมุนและหายใจตอนยืน รอยร้าวพลังตามทางเดินจะค่อยจางภายใน 7 วินาที
- ทุกการเดินมีวงออร่าที่พื้น ชาร์จก่อนพุ่ง กรอบล็อกเป้า ทางพลัง และสโลว์โมก่อนถึงเป้า เวลาสังหารจะเข้าประชิด ง้างท่า อวตารโจมตี ศัตรูรับแรงแล้วสลาย ก่อนเข้าประจำช่อง รูปทรงและท่าทางต่างกันตามชนิดหมาก
- เปิด **เสียงอวกาศ · ไซไฟอนิเมะ** เพื่อฟังเสียงล็อกเป้า ชาร์จ บีม พุ่ง และปะทะ ปรับความดังด้วยแถบ **ระดับเสียงเอฟเฟกต์** ได้
- เสียงเดิน โจมตี ปะทะ ตาย และรุก มีอย่างละ 4 แบบต่อหมาก สลับไม่ซ้ำติดกัน พร้อมเสียงอีเวนท์ขู่สองตัว รุกฆาต และจังหวะสำคัญ
- เสียงแต่ละหมากใช้บุคลิกต่างกัน: เบี้ยแทงสั้น ม้าพัลส์ฉีกอากาศ บิชอปบีมค้าง รุคมอเตอร์และปืนใหญ่ ควีนคริสตัลไล่ระดับ คิงคอร์ดโล่หนัก ปุ่มปิดเสียงบน HUD ไม่ข้ามฉากต่อสู้
- คัตซีนข้ามได้ ลดเอฟเฟกต์ได้ และเสียงเปิด/ปิดได้
- ลองฉาก **ม้า · พุ่งทะลวงเงา** ในสนามฝึก แล้วเดิน c3 → d5 เพื่อดูฉากโจมตีใหม่ทันที

บอตเป็น minimax ในเครื่อง ไม่ใช่ Stockfish ระดับเหล่านี้ไม่มีการรับรอง Elo

## สร้างไฟล์ใหม่จาก source

ใช้ Node.js 24 ในโฟลเดอร์ repository:

```sh
npm ci
npm run build:offline
npm run test:offline
```

ไฟล์ส่งให้คนทดสอบอยู่ที่ `offline/Special-Chess-Offline.html` โฟลเดอร์ `dist-offline` เป็นผล build ชั่วคราว

สำหรับแก้โค้ดพร้อมดูผล ใช้ `npm run dev:offline` แล้วเปิดหน้า `/offline.html` ของ Vite ไม่ต้องเปิด multiplayer server

## การทดสอบ

ทดสอบไฟล์ที่แพ็กแล้วด้วย Chromium โดยปิดเครือข่าย ผ่านบอตทั้งสามระดับ การเซฟ/ย้อนตา ยกเลิกการคิด สนามฝึก และหน้าจอขนาดมือถือ ไม่มี request ภายนอกหรือ WebSocket

เครื่อง cloud นี้มีนโยบายเบราว์เซอร์บล็อก `file://` จึงส่ง HTML เดียวกันให้เบราว์เซอร์ผ่านหน่วยความจำแทน (`OFFLINE_TEST_TRANSPORT=memory npm run test:offline`) การดับเบิลคลิกเปิดไฟล์จริงยังไม่ได้ยืนยันในเครื่องนี้ ชุดทดสอบปกติและ CI ใช้ `file://` โดยตรง

การเปิดไฟล์ HTML บนมือถือจริงขึ้นกับเบราว์เซอร์และแอปจัดการไฟล์ของอุปกรณ์ ยังต้องทดสอบบน Android/iOS เพิ่ม
